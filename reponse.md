1. Différence entre Git et GitHub ?
•	Git = un outil installé sur ton ordinateur qui permet de sauvegarder l'historique de ton code (versions)
•	GitHub = un site web qui héberge tes projets Git en ligne pour les partager
2. À quoi sert git init ? → Elle transforme un dossier normal en un "dépôt Git", c'est-à-dire qu'elle dit à Git : "commence à surveiller ce dossier"
3. Quelle commande envoie un projet sur GitHub ? → git push (après avoir configuré le lien avec GitHub)
4. Pourquoi utilise-t-on les branches ? → Pour travailler sur une nouvelle fonctionnalité sans toucher au code principal. Chaque branche est comme une copie parallèle du projet.
5. Commande pour voir l'historique des commits ? → git log
